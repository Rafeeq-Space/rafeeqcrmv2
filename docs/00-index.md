# فهرس توثيق المشروع

توثيق تشغيلي وتقني لكل ميزة في المشروع — إزاي تشتغل، إزاي تعدّها، وأهم التفاصيل والقيود المعروفة. كل ملف مستقل بذاته.

> **ملاحظة:** الملف ده مختلف عن [`PROJECT_OVERVIEW.md`](../PROJECT_OVERVIEW.md) (تدقيق تقني كامل مكتوب لمساعدة الذكاء الاصطناعي يفهم الكود بسرعة) و[`CLAUDE.md`](../CLAUDE.md) (تعليمات عمل داخل المشروع). التوثيق هنا مكتوب عشانك انت — تشغيلي بالدرجة الأولى، مع تفاصيل تقنية لما تكون مهمة.

## الملفات المتاحة

- [**Google Sheets**](google-sheets.md) — ربط شيت جوجل كمصدر ليدز، الإعداد، مزامنة الحالة ثنائية الاتجاه، مطابقة الحقول.
- [**Bevatel**](bevatel.md) — الشات (واتساب) والمكالمات، الإسناد التلقائي والثابت (Sticky)، مزامنة المكالمات المردود عليها، القيود المعروفة.
- [**الإشعارات**](notifications.md) — إشعارات داخل الموقع + Push، ثغرة الخصوصية اللي اتصلحت، ليه اخترنا Polling بدل Realtime.

## قادم لاحقًا

المشروع كبير، وده أول دفعة — هيتزاد تباعًا:
- الليدز والحملات (مصادر الليدز التانية: فيسبوك، تيك توك، سناب شات)
- الأدوار والصلاحيات (Roles/Permissions) لكل مستوى (سوبر أدمن، أدمن العميل، مدير مبيعات، موظف)
- التارجت الشهري وتقارير الفريق
- نظام الجلسات والكوكيز (Sessions/Cookies)
- تكامل Rafeeq Social (واتساب البديل)
